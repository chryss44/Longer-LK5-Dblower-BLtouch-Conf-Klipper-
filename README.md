Configuration Klipper de la Longer LK5 Pro (équipée avec board Robin E3 V1.1), dual blower et BLTouch.
Mettre le firmware.bin sur la SD carte puis démarrer l'imprimante pour que le firmware soit chargé (attendre max 2 min).
Au redémarrage, avec un image PI Mainsail par exemple en integrant le fichier Print.cfg, tout devrait-être opérationnel.
